# Задача: подписи этапов, типы задач и планы задач

## Что сделать

Этапы воронки остаются этапами и столбцами канбана. В проекты их не переименовывать. У этапа своего статуса нет.

Статусы «В процессе», «Готово» и «Отменено» есть только у задач, которые план создаёт на лицевом счёте при входе на этап.

В «Настройке» три пункта, по приёму Odoo CRM, с полями взыскания:

- «Этапы воронки» — подпись правил перехода под названием столбца, как поле «Требования» у этапа сделки;
- «Типы задач» — справочник, как «Типы активностей»;
- «Планы задач» — карточка плана на этап, как план активностей.

Коды E0–E14 и порядок столбцов не меняются. Имена — из `01-технические-требования/2026-10-23_matrica-voronki.md`. P1 и P2 столбцами основной доски не становятся. Карточка лицевого счёта стоит в одном столбце — самом позднем по цепочке.

## Подпись столбца

В «Этапах воронки» список столбцов в порядке канбана. Под названием — подпись входа. Её правят в настройке. На канбане тот же текст стоит под заголовком столбца серым. Длинный текст обрезается, полный открывается по наведению. Порядок столбцов здесь не перетаскивается.

Подпись собирается из трёх полей. Этап не видит шаблоны и поля чужих задач, только их статусы:

- из какого этапа карточка может прийти;
- какой статус должны иметь задачи того этапа: все обязательные «Готово», либо ещё есть «В процессе», либо задачи «Отменено»;
- можно ли перенести карточку вручную.

Сверху конструктора — сценарий, по умолчанию «Базовый».

Стартовые подписи сценария «Базовый»:

| Столбец | Подпись |
|---------|---------|
| Новый должник | Входящих переходов нет. Вручную нет |
| Автообзвон | Из «Новый должник», задача запуска в статусе «Готово». Вручную да |
| Уведомление/Предупреждение | Из «Автообзвон», у задач ещё есть «В процессе». Вручную да |
| Отключение услуг | Из «Уведомление/Предупреждение», обязательные задачи «Готово». Вручную да |
| Подготовка пакета на исполнительную надпись | Из «Отключение услуг» или «Уведомление/Предупреждение», обязательные задачи «Готово». Вручную да |
| Направлено нотариусу | Из «Подготовка пакета на исполнительную надпись», обязательные задачи «Готово». Вручную да |
| Исполнительная надпись совершена | Из «Направлено нотариусу», обязательные задачи «Готово». Вручную да |
| Отказ нотариуса | Из «Направлено нотариусу», обязательные задачи «Готово». Вручную да |
| Исковое заявление в суд | Из «Отказ нотариуса» или «Исполнительная надпись совершена», обязательные задачи «Готово». Вручную да |
| Судебное решение получено | Из «Исковое заявление в суд», обязательные задачи «Готово». Вручную да |
| Направлено в ОПИ | Из «Исполнительная надпись совершена» или «Судебное решение получено», обязательные задачи «Готово». Вручную да |
| Меры ОПИ приняты | Из «Направлено в ОПИ», обязательные задачи «Готово». Вручную да |
| Взыскано | Из любого этапа цепочки, задачи «В процессе» или «Готово». Вручную да |
| Невозможность взыскания | Из «Меры ОПИ приняты», обязательные задачи «Готово». Вручную да |
| Подготовка документов о списании безнадежной задолженности | Из «Невозможность взыскания», обязательные задачи «Готово». Вручную да |

Нулевой долг ставит незакрытым задачам «Отменено» и открывает «Взыскано». Ручной переход не ограничен направлением «только вперёд», если у столбца включён ручной вход и у специалиста есть право смены этапа. Сохранение пишет, кто и какую подпись изменил. Доска читает сохранённые правила.

## Типы задач

Список: название, краткое описание по умолчанию, через сколько планировать, тип.

Тип — закрытый набор. Это не звонок, встреча и письмо из CRM:

- Заполнить поле
- Сформировать автообзвон по шаблону
- Загрузить документ
- Сформировать документ по шаблону
- Отправить email по шаблону
- Отправить SMS по шаблону
- Согласовать
- Передать во внешнюю систему
- Остановить сценарий

Новый бланк или письмо — новая строка справочника с тем же типом и другим шаблоном. Стартовые строки: голосовое сообщение, SMS, email, предупреждение PDF, заявление, расчёт задолженности, иск, акт о списании, скан вручения, дата вручения, пакет в личный кабинет БНП, исполнительный документ в ОПИ, факт списания в АИС «Расчёт-ЖКУ».

## Планы задач

Карточка плана привязана к этапу воронки. На этап — один план сценария «Базовый». Название плана совпадает с этапом.

Строки плана, как «Активности к созданию»:

- тип задачи из справочника;
- краткое описание;
- назначение — специалист или система;
- ответственный;
- интервал и единица;
- триггер — «при входе на этап» или «после предыдущей строки плана».

При входе лицевого счёта на этап строки плана становятся его задачами. Обязательная строка держит переход дальше, пока не «Готово». Необязательная строка переход не держит: ручной обзвон появляется, только если автоматический звонок пункт не закрыл.

Стартовые строки планов:

- Новый должник — признак запуска сценария, заполнить поле. Ставит массовое «Запустить сценарий».
- Автообзвон — голосовое сообщение по шаблону, статус звонка, доля прослушивания (успех от 70%). Ручной обзвон тем же шаблоном — необязательная строка.
- Уведомление/Предупреждение — SMS, email, PDF предупреждения, скан вручения или акт невручения, дата вручения.
- Отключение услуг — согласовать список, задание поставщику, дата приостановления, затем одна ветка: возобновление или отмена до факта.
- Подготовка пакета на исполнительную надпись — заявление и расчёт по шаблону, доверенность и сканы, тариф, дата вручения предупреждения или уведомления.
- Направлено нотариусу — пакет в личный кабинет БНП с ЭЦП, дата отправки.
- Исполнительная надпись совершена — номер, дата, скан надписи.
- Отказ нотариуса — постановление об отказе, дата отказа. Возврат на доработку снова создаёт строки плана подготовки пакета, новый тип не добавляет.
- Исковое заявление в суд — иск по шаблону, дата подачи, статус рассмотрения.
- Судебное решение получено — приказ или решение, исполнительный лист, дата получения.
- Направлено в ОПИ — передача документа, статус «возбуждено», дата направления.
- Меры ОПИ приняты — состав мер, остаток (долг, пеня, тариф), статус производства.
- Взыскано — остановить сценарий, дата погашения.
- Невозможность взыскания — акт ОПИ, дата акта.
- Списание — акт о списании по шаблону, согласование, передача факта в «Расчёт-ЖКУ».

## Что не менять

Состав и порядок столбцов канбана. Одна карточка в одном текущем этапе. Статусная лента. Вкладка «Активности». Ветвь P1–P2.
