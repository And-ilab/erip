# Руководство по ручной настройке рабочего места для автоматической подписи ЭЦП (ГосСУОК / АВЕСТ AvPass) в Microsoft Edge (режим Internet Explorer)

Документ описывает пошаговую настройку компьютера специалиста для работы с функцией **«Подписать и собрать архив»** в ПМ «Работа с задолженностью» без использования скриптов, а также способ быстрой проверки и устранения типовых ошибок.

---

## 1. Предварительные требования на рабочем месте

Перед настройкой браузера убедитесь, что на компьютере установлены компоненты НЦЭУ / ЗАО «АВЕСТ» (дистрибутив: https://nces.by/pki/info/software):

1. **Криптопровайдер и Персональный менеджер сертификатов АВЕСТ** («Комплект абонента АВЕСТ» для РУЦ ГосСУОК).
2. **Драйвер носителя ключевой информации AvPass** (USB-токен определяется в системе, в «Персональном менеджере сертификатов АВЕСТ» виден личный сертификат и актуальный СОС/CRL).
3. **Веб-плагин `AvCMXWebP`** (`AVEST CryptMail X Web Plugin`, CLSID `{35B35038-9C01-5D75-943F-5A19E32AC230}`).
   - Проверить наличие файлов плагина на диске:
     - `C:\ProgramData\Avest\AvCMXWebP\x86\npAvCMXWebP.dll`
     - `C:\ProgramData\Avest\AvCMXWebP\x64\npAvCMXWebP.dll`

---

## 2. Шаг 1. Настройка зон безопасности и ActiveX в Windows (`inetcpl.cpl`)

Режим Internet Explorer внутри Microsoft Edge использует системные настройки безопасности Windows («Свойства браузера»).

### 2.1. Открытие окна «Свойства браузера»
1. Нажмите на клавиатуре **`Win + R`**.
2. Введите команду:
   ```text
   inetcpl.cpl
   ```
   и нажмите **Enter** (либо откройте *Панель управления → Сеть и Интернет → Свойства браузера*).

### 2.2. Добавление адреса ПМ в «Надёжные сайты» и отключение Защищённого режима
1. Перейдите на вкладку **«Безопасность»**.
2. Выберите зелёную иконку **«Надёжные сайты»** (Trusted sites).
3. **Снимите галочку «Включить защищённый режим (требуется перезапуск браузера)»** внизу окна.
   > **Почему это обязательно:** при включённом Защищённом режиме процесс IE работает с низким уровнем целостности (Low Integrity) и Windows блокирует библиотеке `AvCryptMail.dll` доступ к каталогу `%APPDATA%\Avest` (возникает ошибка `3895066916` / `AVCMR_INTERNAL_ERROR`).
4. Нажмите кнопку **«Сайты»** (Sites):
   - **Снимите галочку** *«Для всех сайтов этой зоны требуется проверка серверов (https:)»* внизу окна.
   - В поле *«Добавить в зону следующий узел»* введите адрес сервера ПМ (например, `http://178.159.47.172`) и нажмите **«Добавить»**.
   - Нажмите **«Закрыть»**.

### 2.3. Разрешение инициализации и выполнения элементов ActiveX (ключевой шаг для `CreateBlob`)
Не закрывая вкладку **«Безопасность»** (при выбранной зоне **«Надёжные сайты»**):

1. Нажмите кнопку **«Другой...»** (Custom level...) внизу в блоке *«Уровень безопасности для этой зоны»*.
2. В открывшемся списке прокрутите до раздела **«Элементы ActiveX и модули подключения»** (ActiveX controls and plug-ins).
3. Установите положение **«Включить» (Enable)** для следующих параметров:
   - **Автоматические запросы элементов управления ActiveX** → `Включить`
   - **Выполнять сценарии элементов ActiveX, помеченных как безопасные для выполнения сценариев** → `Включить`
   - **Запуск элементов ActiveX и модулей подключения** → `Включить`
   - **Инициализация и выполнение сценариев элементов ActiveX, не помеченных как безопасные для выполнения сценариев** → **`Включить`**
     > **Критически важно:** плагин `AvCMXWebP` не реализует интерфейс `IObjectSafety`. Если здесь стоит «Отключить» или «Предлагать», в Edge IE Mode объект `<object id="oavcmx">` создаётся пустым, и метод **`CreateBlob` отсутствует**!
   - **Поведение двоичного кода и сценариев** → `Включить`
   - **Разрешать использование элементов ActiveX без запроса (только утверждённые домены)** → `Включить`
4. Нажмите **«ОК»** и в окне предупреждения подтвердите изменение параметров зоны (**«Да»**).

### 2.4. Отключение 64-битного расширенного защищённого режима
1. В том же окне «Свойства браузера» (`inetcpl.cpl`) перейдите на вкладку **«Дополнительно»** (Advanced).
2. В разделе **«Безопасность»** (Security) найдите пункт:
   - **«Включить расширенный защищённый режим»** (Enable Enhanced Protected Mode) — **снимите галочку**.
   - Если рядом есть пункт *«Включить 64-разрядные процессы для расширенного защищённого режима»* — также **снимите галочку**.
3. Нажмите **«Применить»** и **«ОК»**.

## 3. Шаг 2. Разрешение надстройки `AvCMXWebP` для всех сайтов

Чтобы браузер не блокировал плагин до нажатия жёлтой панели внизу экрана:

1. Откройте `inetcpl.cpl` → вкладка **«Программы»** → кнопка **«Надстройки»** (Manage add-ons).
2. В выпадающем списке слева *«Отображать:»* выберите **«Все надстройки»** (All add-ons).
3. В списке найдите **«AVEST CryptMail X Web Plugin»** (`AVEST plc`).
4. Убедитесь, что его состояние — **«Включено»**.
5. Дважды щёлкните по **«AVEST CryptMail X Web Plugin»** → если активна кнопка **«Разрешить на всех сайтах»** (Allow on all sites), нажмите её (в списке разрешённых сайтов должна появиться звёздочка `*`), затем нажмите **«Закрыть»**.

## 4. Шаг 3. Настройка Microsoft Edge для автоматического открытия `/ie-sign/` в режиме IE

Есть два способа: **Вариант А** (через интерфейс настроек Edge — действует 30 дней, затем обновляется в 1 клик) и **Вариант Б** (бессрочно через корпоративный список сайтов `sites.xml` в реестре).

### Вариант А. Вручную через настройки Microsoft Edge (без реестра)
1. Откройте Microsoft Edge и перейдите по адресу:
   ```text
   edge://settings/defaultBrowser
   ```
   *(Меню `...` → Настройки → Браузер по умолчанию).*
2. В поле **«Разрешить перезагрузку сайтов в режиме Internet Explorer (режим IE)»** выберите **«Разрешить»** (Allow) и нажмите кнопку **«Перезапустить»**.
3. В блоке ниже **«Страницы для режима Internet Explorer»** нажмите кнопку **«Добавить»** и добавьте два адреса (подставьте IP или домен вашего сервера ПМ):
   - `http://178.159.47.172/ie-sign/`
   - `http://178.159.47.172/ie-sign/index.html`
   > **Важно:** добавляйте именно путь с `/ie-sign/`, а не корень `http://178.159.47.172/`, иначе весь интерфейс Angular ПМ будет открываться в старом IE11.

### Вариант Б. Бессрочно через политику списка сайтов (`sites.xml`)
Сервер ПМ автоматически отдаёт XML-список сайтов по адресу:
`http://178.159.47.172/api/v1/ie-mode/sites.xml` (в нём прописано открывать в `IE11` только `/ie-sign` и `/ie-sign/index.html`).

Чтобы подключить его бессрочно:
1. Запустите **PowerShell от имени Администратора** (если ветка `Policies` закрыта для обычного пользователя) и выполните:
   ```powershell
   $list = "http://178.159.47.172/api/v1/ie-mode/sites.xml?host=178.159.47.172"
   $policy = "HKLM:\SOFTWARE\Policies\Microsoft\Edge"
   New-Item -Path $policy -Force | Out-Null
   New-ItemProperty -Path $policy -Name InternetExplorerIntegrationLevel -PropertyType DWord -Value 1 -Force | Out-Null
   New-ItemProperty -Path $policy -Name InternetExplorerIntegrationSiteList -PropertyType String -Value $list -Force | Out-Null
   New-ItemProperty -Path $policy -Name InternetExplorerIntegrationZoneAllowed -PropertyType DWord -Value 1 -Force | Out-Null
   ```
2. Откройте в Edge служебную страницу:
   ```text
   edge://compat/enterprise
   ```
   и нажмите кнопку **«Принудительное обновление» (Force update)** — в таблице появится строка `178.159.47.172/ie-sign` с режимом `IE11`.

## 5. Шаг 4. Все настройки реестра одной командой (альтернатива ручному прокликиванию `inetcpl.cpl`)

Если нужно быстро выставить все пункты Шага 1 и Шага 2 через PowerShell (выполняется под текущим пользователем Windows без прав администратора):

```powershell
$hostName = "178.159.47.172"

# 1. Добавить IP в Надёжные сайты (Зона 2)
$range = "HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings\ZoneMap\Ranges\EripSign"
New-Item -Path $range -Force | Out-Null
New-ItemProperty -Path $range -Name ":Range" -PropertyType String -Value $hostName -Force | Out-Null
New-ItemProperty -Path $range -Name "http" -PropertyType DWord -Value 2 -Force | Out-Null
New-ItemProperty -Path $range -Name "https" -PropertyType DWord -Value 2 -Force | Out-Null

# 2. Разрешить инициализацию ActiveX (1201=0) и отключить Защищённый режим (2500=3, 2702=3)
foreach ($z in @("1","2","3")) {
  $zp = "HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings\Zones\$z"
  if (Test-Path $zp) {
    Set-ItemProperty -Path $zp -Name "1200" -Value 0 -Type DWord
    Set-ItemProperty -Path $zp -Name "1201" -Value 0 -Type DWord
    Set-ItemProperty -Path $zp -Name "1208" -Value 0 -Type DWord
    Set-ItemProperty -Path $zp -Name "1405" -Value 0 -Type DWord
    Set-ItemProperty -Path $zp -Name "2000" -Value 0 -Type DWord
    Set-ItemProperty -Path $zp -Name "2500" -Value 3 -Type DWord
    Set-ItemProperty -Path $zp -Name "2702" -Value 3 -Type DWord
  }
}

# 3. Включить 32-битный процесс вкладки IE и разрешить CLSID AvCMXWebP на всех доменах
$ieMain = "HKCU:\Software\Microsoft\Internet Explorer\Main"
Set-ItemProperty -Path $ieMain -Name "Isolation" -Value "PMIL" -Type String
Set-ItemProperty -Path $ieMain -Name "Isolation64Bit" -Value 0 -Type DWord
Set-ItemProperty -Path $ieMain -Name "TabProcGrowth" -Value 1 -Type DWord

$ext = "HKCU:\Software\Microsoft\Windows\CurrentVersion\Ext\Stats\{35B35038-9C01-5D75-943F-5A19E32AC230}\iexplore"
New-Item -Path $ext -Force | Out-Null
Set-ItemProperty -Path $ext -Name "Flags" -Value 4 -Type DWord
New-Item -Path "$ext\AllowedDomains\*" -Force | Out-Null
New-Item -Path "$ext\AllowedDomains\$hostName" -Force | Out-Null

# 4. Перезапустить процессы Edge и IE
taskkill /F /IM msedge.exe /T 2>$null
taskkill /F /IM iexplore.exe /T 2>$null
```

*(Либо запустите готовый скрипт из репозитория: `powershell -ExecutionPolicy Bypass -File app\tools\edge-ie-mode.ps1 -Origin http://178.159.47.172`).*

## 6. Как работает автоматический процесс подписания для пользователя

1. Специалист открывает карточку дела в ПМ на вкладке **«Комплект»**:
   - Пока комплект неполный (нет заявления, расчёта, доверенности, даты вручения предупреждения, тарифа или e-mail для уведомлений) — все три кнопки (**«Подписать и собрать архив»**, **«Скачать архив»**, **«Отправить»**) неактивны.
   - Когда все документы и поля заполнены, но ещё не подписаны — активна только кнопка **«Подписать и собрать архив»**.
2. Специалист вставляет носитель **AvPass** и нажимает **«Подписать и собрать архив»**.
3. Автоматически открывается новая вкладка в **режиме Internet Explorer** (`/ie-sign/index.html?t=...&n=...`), при каждом нажатии генерируется новая уникальная ссылка.
4. Страница сама:
   - проверяет плагин `AvCMXWebP`;
   - считывает сертификат из личного справочника АВЕСТ (`AVCMF_NO_AUTH` + `AVCM_TYPE_MY`);
   - скачивает PDF комплекта и вызывает окно ввода пароля контейнера AvPass.
5. Специалист **один раз вводит пароль** в системном окне АВЕСТ.
6. Все документы комплекта автоматически подписываются отсоединённой подписью PKCS#7 (`.p7s`), подписи сохраняются на сервере и собирается ZIP-архив для БНП.
7. Появляется всплывающее уведомление:
   > *«Архив документов собран и доступен для скачивания/отправки, пожалуйста вернитесь в ПМ»*
8. Специалист возвращается на вкладку ПМ — кнопки **«Скачать архив»** и **«Отправить»** уже активны.

## 7. Диагностика и устранение типовых ошибок

На странице `/ie-sign/` под заголовком выводится строка диагностики. В норме она выглядит так:

```text
сборка страницы: 20261102c · object#oavcmx: есть · CreateBlob: да (typeof=object, вызов ок) · Version: 1.1.20 · avcmx(): да · avcmx().blob(): ок
```

| Симптом / Ошибка | Причина | Решение |
|---|---|---|
| `CreateBlob: нет` | В зоне «Надёжные сайты» запрещена инициализация небезопасных ActiveX (`1201 = 3`) или не перезапущен браузер после правок | В `inetcpl.cpl` → Надёжные сайты → Другой → включить *«Инициализация и выполнение сценариев элементов ActiveX, не помеченных как безопасные»* (`1201 = 0`), затем закрыть все окна `msedge.exe` и `iexplore.exe`. |
| Код `3895066916` (`AVCMR_INTERNAL_ERROR`) | Включён Защищённый режим IE (Low Integrity), блокирующий доступ к `%APPDATA%\Avest` | В `inetcpl.cpl` → Безопасность → Надёжные сайты → снять галочку *«Включить защищённый режим»* (`2500 = 3`) и перезапустить браузер. |
| Страница открылась в обычном Edge (нет значка IE слева от адреса) | URL `/ie-sign/` не добавлен в список страниц режима IE или не обновился `sites.xml` | В `edge://settings/defaultBrowser` добавить `http://<адрес>/ie-sign/index.html` и `http://<адрес>/ie-sign/`, либо в `edge://compat/enterprise` нажать **Force update**. |
| `HTTP 404` при открытии `/ie-sign/?t=...` | На сервере старый конфиг `nginx` без `index index.html` в `location ^~ /ie-sign/` | Обновить код на сервере (`git pull origin code` и `docker compose up --build -d`). |
